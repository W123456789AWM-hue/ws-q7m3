# AI 录音思考助手 · 电脑端（v0.9 · Windows / Mac）

**手机、平板、别的电脑都可以当录音设备，几台同时录也行；这台电脑把所有设备的录音合成一场，
交给 AI 听（OpenAI gpt-audio-1.5），写出听写文字并做发散复盘；结果存在电脑上、同步到 NAS，
手机 App 和其他电脑的浏览器都能查看。**

```
客厅手机 ─┐
办公室 iPad ─┼─录音切片上传（静音不传，断网先存设备）──► 这台电脑
这台电脑的麦克风 ─┘                                       │ 每台设备各自按停顿切成段落
                                                          │ 几台设备的段落按录音时间排好，合成一场
                                                          │ 到了复盘时机（实时 / 自定义周期），一起交给 AI 听
                                                          ▼
                                                  存本机 + 同步 NAS
手机 App / 其他电脑浏览器 ◄──查看复盘、听写、历史、日复盘；修改设置──┘
```

## 安装成独立程序（推荐）

不用装 Python，像普通软件一样有自己的窗口，关掉窗口就退出。

- **Windows**：双击安装程序 `AIMind-Setup-<版本>.exe` → 安装，之后从桌面或开始菜单打开。
  装在 `%LOCALAPPDATA%\Programs\AIMind`（不要管理员权限，可选开机自启）；卸载在「设置 → 应用」。覆盖安装就是升级。
  第一次启动时 Windows 防火墙弹窗要点「允许访问」，手机才能连进来。
  也有解压即用的 `AIMind-Windows.zip`：**一定要先解压到短路径（如 `D:\AIMind`）再运行**，
  不要在 WinRAR 等压缩软件里直接双击运行（会被临时解压到很深的目录，报“文件名或扩展名太长”）。
- **Mac**：打开 `AIMind-Mac-apple-silicon.dmg`（M1/M2/M3/M4 芯片）或 `AIMind-Mac-intel.dmg`，把「AI录音思考助手」拖进“应用程序”。
  没有苹果开发者签名，第一次打开要在“应用程序”里**右键 → 打开**；如果提示“已损坏”，在终端运行
  `xattr -cr "/Applications/AI录音思考助手.app"` 再打开。
- 独立程序的数据存在：Windows `%APPDATA%\AIMind\data`，Mac `~/Library/Application Support/AIMind/data`。
  **从源码版换过来**：把 `server/data` 里的东西复制到上面这个目录，设置和历史都会保留。
- 启动时先播放透明背景的启动动画（约 8 秒，点一下或按任意键可以跳过），放完自动打开主窗口。
  在「设置 → 启动动画」里可以关掉或调速度（0.5×–3×），Windows 上还能直接预览。动画素材用 `packaging/make_splash.py` 从 `packaging/splash_source.mp4` 生成。
- 独立程序不带“本机识别成文字”（SenseVoice / Whisper，体积太大）；要用这个功能请用下面的源码方式启动。

**自己打包**：Windows 双击 `packaging/build_windows.bat`（生成 `dist/AIMind-Setup-<版本>.exe` 安装程序和 `dist/AIMind-Windows.zip` 绿色版）；
Mac 运行 `bash packaging/build_mac.sh`（生成 `dist/AIMind-Mac.dmg`）。没有 Mac 的话用仓库里的 GitHub Actions「Build all」云端打包。

## 用源码启动

- **Windows**：双击 `start.bat`。
- **Mac**：双击 `start.command`。第一次如果提示“无法打开”，在访达里**右键 → 打开**。需要 Python 3.10 以上。
- 第一次运行会自动安装依赖，约 1 分钟。

**从 v0.8 升级**：把旧版文件夹里的 `data` 整个复制到本文件夹（`server/data`），设置、历史记录、测试集都会保留。

## 第一次设置（右上角「设置」）

1. **AI 听录音（OpenAI）**：填 OpenAI 的 API Key，点「测试 AI 能不能听到录音」。模型默认 `gpt-audio-1.5`。
2. **小复盘**（录音过程中）：选实时（每说完一段）或自定义周期（每隔 N 分钟）。填「关于我」。
3. **大复盘**（总结）：整场结束时的总复盘（可关）、每天几点做日复盘、月复盘（月底 / 下月 1 号 / 不做）、
   年复盘（12 月 31 日 / 次年 1 月 1 日 / 不做）。月复盘汇总当月的日复盘，年复盘汇总每月的月复盘，逐级往上，
   不会把一整年的原始内容发给 AI。电脑没开错过了时间，下次打开会自动补做。顶部「复盘报告」里可以随时查看或手动生成。
4. **文字 AI**（可不填）：总复盘、日 / 月 / 年复盘用；不填就用上面的 OpenAI。
5. **NAS 目录**：Windows 填 `\\192.168.1.10\recordings`；Mac 先在访达连上 NAS，再填 `/Volumes/共享文件夹名`。

**费用（估算）**：每小时说话约 1.2 美元（只发有人说话的部分）。几台设备在同一个房间同时录，
同一段话会被听好几遍，费用也会翻倍——同一个房间放一台就够了。

**在线更新**：有新版本时右上角会出现「新版本 x.x.x」，点开看更新内容，点「下载并安装」，约 10 秒后自动重新打开。
录音中不会更新；录音、复盘、设置都不受影响。设置 → 通用 → 软件更新里可以关掉自动检查、填下载镜像。
手机 App 在「设置 → 软件更新」里检查（通过电脑下载）：安卓点一下就能装；iPhone 需要用电脑重新签名安装。

**省 token**：右下角状态栏显示今天的 AI 用量（点开看明细和省钱建议）。程序已经自动做了这些，不影响复盘质量：
发给 AI 前去掉每句话前后多余的静音；固定不变的说明放在最前面，命中 OpenAI 的提示缓存（这部分按半价或更低计费）；
AI 返回的格式坏了时，用文字 AI 修，不再把整段录音重发一遍。

**隐私**：录音会上传到 OpenAI。录别人说话时请先告知对方。

## 连接录音设备（右上角「设备连接」）

1. 面板里有这台电脑的地址（如 `http://192.168.1.20:8765`）和**连接口令**，在每台设备的 App「设置」里照着填。
2. **每台设备填一个不同的「这台设备的名字」**（如“客厅手机”“办公室 iPad”），电脑上就按名字分开显示，AI 也知道哪段话是哪台录的。
3. 第一次启动时 Windows 防火墙会弹窗，要点「允许访问」。
4. **外出也要传**：电脑和手机都装 Tailscale（免费），同一账号登录，面板里会多出 `http://100.x.x.x:8765` 的备用地址。

**一场是怎么开始和结束的**

- 任何一台设备开始传录音（或点「用电脑麦克风录」），就开始一场；其他设备随时加入同一场。
- 所有设备都点了停止，或者都超过 30 分钟（设置里可改）没传录音，这一场自动收尾：补最后一次复盘 + 整场总复盘。
- 想马上结束，点顶部「结束本场」。过了零点自动换成新一天的一场。
- 电脑没开时设备会把录音先存着，连上后补传；补传的录音按真实录音时间排进去，时间不会乱。

**在其他电脑上查看**：「设备连接」里复制「在其他电脑的浏览器里查看结果」的地址，在另一台电脑浏览器打开即可。

## 还保留的功能

- **本地识别（不上传录音）**：设置里把「AI 怎么拿到内容」改成“先在本机识别成文字”，安装 `requirements-local.txt`
  （SenseVoice / Paraformer，首次自动下载约 240MB）。有 NVIDIA 显卡可以双击 `install_whisper_gpu.bat` 装 Whisper large-v3。
- **识别测试**：从自己的录音里挑句子标注，比较几种本地识别模型的错误率（只对本地识别模式有意义）。
- **文字测试 / 导入 WAV**：不录音也能试 AI 复盘效果。

## 文件存在哪

```
data/
  config.json            设置
  devices.json           连接过的设备（编号、名字、最后在线）
  inbox/                 设备刚传来、还没处理的录音片
  sessions/日期_时间/
    audio_<设备>_001.wav   每台设备的完整录音（每 30 分钟一个文件）
    transcript.jsonl       听写文字，带时间和设备
    report.md              可读报告
    session.json           全部结构化数据
  daily/日期.md          日复盘
  monthly/2026-11.md     月复盘
  yearly/2026.md         年复盘
  usage.json             每天的 AI 用量（token）
  testset/               识别测试集
```

配置了 NAS 的话，`sessions`、`daily`、`monthly`、`yearly` 会同步一份过去。

## 开发

代码结构和改代码的约定见仓库根目录的 `CLAUDE.md`。

```bash
pip install -r requirements-dev.txt
python -m pytest            # 全部测试（AI 用 tools/mock_openai.py 代替，不花钱）
ruff check aimind tools tests
python -m tools.device_sim --device test --name 测试设备   # 模拟一台设备往运行中的程序上传录音
```
