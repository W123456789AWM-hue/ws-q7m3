# AI 录音思考（手机端：iPhone + 安卓）

**手机只负责录音；电脑把录音直接交给 AI 听（OpenAI gpt-audio-1.5）做发散复盘；结果同步到 NAS；手机上可以查看和设置。**

```
手机 App ──录音切片上传（静音不传，断网先存手机）──► 电脑上的「AI 录音思考助手」（Windows 或 Mac）
                                                      │ AI 直接听录音 → 听写文字 + 发散复盘 + 语气线索
                                                      ▼
                                              存电脑 + 同步 NAS
手机 App ◄──查看复盘、听写、历史、日复盘；修改设置──────┘
```

必须配合电脑端（`ai_mind_desktop_v8.zip` 或更新版本）一起用。

## 手机上能做什么

- **录音**：后台持续录音；每 10 秒切一片传给电脑；没人说话的片只传一个标记，不传音频。
- **看结果**：首页的「AI 复盘」和「转写」会自动刷新；「历史」里看以前每一场；「复盘报告」里按日 / 月 / 年查看或生成。
- **立即复盘 / 重试**：一键让电脑马上复盘，或重试失败的复盘。
- **设置**：
  - 手机上的：电脑地址和口令、这台设备的名字、仅 WiFi 上传、静音不上传、打开自动录音、麦克风增益和降噪。
  - 电脑上的（通过网络修改）：小复盘方式（实时 / 自定义周期）、间隔、大复盘（整场总复盘、日 / 月 / 年复盘的时机）、关于我、常用词、OpenAI Key 和听录音的模型、NAS 目录，并可以远程测试 AI 能不能听到录音、测试 NAS。

## 外出工作时：录音照样传回电脑

手机在外面（用移动网络，或别处的 WiFi）时，够不着家里电脑的局域网地址。办法是给手机和电脑之间搭一条加密的专线，
推荐用 **Tailscale**（个人使用免费，不用改路由器）：

1. **电脑**：到 tailscale.com 下载安装 Windows 版，登录（可以用 Google / Microsoft / Apple 账号）。
2. **手机**：在应用商店安装 Tailscale，用**同一个账号**登录，把开关打开。
3. 电脑上打开「AI 录音思考助手」→「设备连接」，「备用地址」里会出现一个 `http://100.x.x.x:8765`。
4. 手机 App →「设置 → 连接电脑」→ 把它填到 **备用地址** →「测试连接」。
5. 确认「仅 WiFi 下上传」是**关闭**的。

之后不用再管：在家时走局域网地址，出门后自动换成备用地址（首页会显示“外出线路”），回家再自动换回来。

- **流量**：用移动网络时，录音会自动压缩到原来的 1/4 再传（实测对识别准确度影响很小）；没人说话的片段本来就不传。
  按每天说话 3 小时算，大约 80–90MB。看结果的界面在移动网络下也会降低刷新频率。
- **不想用流量**：打开「仅 WiFi 下上传」，在外面录的先存手机（默认最多 3000MB，静音不占空间），回到 WiFi 后自动按顺序补传，每句话的时间不会乱。
- **电脑要开着**：家里的电脑没开机或程序没运行时，同样是先存手机、之后补传。
- 连不上备用地址时：检查手机和电脑上的 Tailscale 都显示已连接；Windows 防火墙里把本程序（Python）在“专用”和“公用”网络都允许。
- 手机同一时间只能开一个 VPN。如果你手机上平时开着别的 VPN / 代理 App，它和 Tailscale 不能同时用，这种情况告诉 Claude，换别的方案。

## 一键打包

**安卓（Windows 电脑）**：双击 **`build_android.bat`**，输入 `y` 回车。

- 自动准备好 Git、Flutter、Java、Android SDK（已有的直接用），装在 `AppData\Local\ai_mind_build`，不改系统设置。
- 完成后安装包在 **`output`** 文件夹：把 `app-arm64-v8a-release.apk` 传到手机上安装。
- 手机用数据线连着电脑并开了 USB 调试时，会问你要不要直接装进手机。
- 出错时把 `output\flutter_log.txt` 发给 Claude。
- 如果手机上装着旧版（在手机上识别的那一版），可以直接覆盖安装。

**不想在自己电脑上装工具**：用仓库根目录的 GitHub Actions「Build all」云端打包，安卓 APK 和 iPhone IPA 一起出。

**iPhone（必须用 Mac）**：终端里运行 `bash build_ios.sh`。第一次会打开 Xcode 让你选 Apple ID 签名。
没有 Mac 的话，可以用工程里的 GitHub Actions 配置（`.github/workflows/build.yml`）云端打包出未签名的 IPA，
再用 Sideloadly / AltStore 签名安装（免费 Apple ID 每 7 天要重签一次）。

## 第一次使用

1. 电脑上启动「AI 录音思考助手」，点 **「设备连接」**，记下地址和口令。Windows 防火墙弹窗要点「允许访问」。
2. 手机打开 App →「去设置」→ 填电脑地址和口令 →「测试连接」。
   有好几台手机/平板一起录的话，每台在「这台设备的名字」里填不同的名字（如“客厅手机”“办公室 iPad”），电脑上会分开显示，内容合在同一场里复盘。
3. 连上后，设置页下方会出现电脑上的设置，可以直接在手机上改。
4. 回到首页点「开始录音」。

## 24 小时使用须知

**安卓**
- 录音时通知栏有一条常驻通知，这是系统要求。
- 首页提示“关闭电池优化”时请允许。小米、华为、OPPO、vivo 等还要手动把本 App 的「自启动 / 后台运行 / 省电策略」设为无限制，并在最近任务里锁定。
- 「强制停止」或重启手机后，需要手动打开 App 重新开始录音。没传完的录音会自动补传。

**iPhone**
- 录音时状态栏有麦克风提示，无法隐藏。
- 在多任务界面上划掉 App，录音一定会停。
- 打完电话后 iOS 偶尔不让后台 App 重新拿回麦克风，最好打开 App 看一眼。
- 第一次连接电脑时会弹出“允许查找本地网络上的设备”，要点允许。

**听写不准时**
- 手机离嘴的距离和环境噪音影响最大：尽量放桌上，不要放口袋和包里。
- 在「我常说的词 / 专有名词 / 英文术语」里填上人名、术语，AI 听写时会按这些词来写。
- 「声音检测灵敏度」调得太高会漏掉小声说话（那些片会被当成静音不上传）。不放心可以先关掉「没人说话的片段不上传」。

**安全与法律**
- 连接口令和录音在局域网里是明文传输（http），只适合在自己家或办公室的网络里用。
- 只录自己参与的对话一般没有问题；偷录他人之间的非公开对话可能违法（例如台湾《刑法》第 315-1 条）。

## 代码结构

```
lib/core/            纯 Dart 核心（不依赖 Flutter，可在电脑上直接测试）
  audio.dart           声音检测
  uploader.dart        切片、手机暂存、按顺序上传、断点补传
  api.dart             和电脑通信：看结果、改设置
  settings.dart        手机上的设置
lib/recorder.dart    麦克风录音流 + 看门狗
lib/app_state.dart   组装
lib/ui/              界面
android/             AndroidManifest + Kotlin 前台服务
build_android.bat    一键打包安卓安装包（Windows）
build_ios.sh         一键打包并安装 iPhone 版（Mac）
tool/core_check.dart 手机核心 ↔ 电脑端 的联调脚本
```
